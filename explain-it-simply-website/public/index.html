Explain it simply
A REST API is a waiter: you say what you want, it carries the request to the kitchen and brings back exactly that plate. It never remembers your order between visits.
Technical breakdown
Stateless request/response over HTTP, with resources addressed by URI and verbs mapping to CRUD: GET to read, POST to create, PUT to replace, DELETE to remove. Payloads are usually JSON; correctness comes from idempotence and status codes, not from server memory.

Who it is for

Developers reading foreign code

Someone else's 60-line function, a legacy shell script, a config loader you did not write. Get the mechanism, the dependencies and what could go wrong.

Students and self-taught programmers

Learn the concept first, then the vocabulary. Key concepts and common mistakes are part of the deep answer, not an afterthought.

Teams onboarding people

The VS Code extension explains the selection, the function at the caret, or the error the editor is already complaining about — inside the file you are reading.

The same answers, inside your editor

The extension keeps the context where it belongs: your selection. Commands are context-aware — with text selected you get Explain Selection, with the caret in a function you get Explain Function, and on a line with a real diagnostic you get Explain Error. Keys are stored in your OS keychain, history stays local, and you choose how much of your source code, if any, is kept afterwards.

This website uses a server-side key. The extension talks to the provider directly with your own key.
